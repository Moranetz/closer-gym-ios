# Frame & Fork v1.1 — Hosted Pro Tier

**Goal:** convert the Pro tier from BYOK-only to a hybrid — keep BYOK as a free secondary path for power-users / developers, and add a hosted "Pro Unlimited" subscription where Marion holds the Anthropic API key and the user pays Apple directly.

**Why now:** ship v1.0 BYOK-only first (clears App Review with minimum surface area), launch on LinkedIn alongside Atlas, then ship v1.1 with hosted Pro 1–2 weeks later.

## Unit economics

Per-game Anthropic cost on the persona-simulation pipeline (~1500 token system prompt + 12-turn average × ~350 tokens per turn = ~5700 input + ~2400 output):

- claude-opus-4-5: ~$0.27/game
- claude-sonnet-4-6: ~$0.05/game

For sparring quality, **sonnet 4.6 is sufficient** — the persona schema does the heavy lifting. Plan on ~$0.05/game on inference.

Apple takes 15% under the Small Business Program (Marion qualifies under $1M ARR). Per dollar collected, ~$0.85 net.

## Architecture

```
┌─────────────┐   StoreKit 2 + receipt    ┌──────────────────────┐
│ iOS app     │ ────────────────────────► │ Apple App Store      │
│             │                           └──────────────────────┘
│             │
│  Settings → Pro Tier:
│    ○ Hosted    ← subscription via Apple
│    ○ BYOK      ← user supplies key (current flow)
│
│  On Pro turn:
│  if hosted:  POST /api/messages  with bearer = receipt
│  else:       POST anthropic.com  with x-api-key = local
│             │
│             │  POST /api/messages
│             ▼
│      ┌──────────────────────────────────────────────┐
│      │ Vercel function (frameandfork.vercel.app/api)│
│      │   1. Verify Apple receipt (StoreKit 2 JWS)   │
│      │   2. Look up user's monthly usage in KV      │
│      │   3. 429 if over cap                         │
│      │   4. Increment counter                       │
│      │   5. Forward to Anthropic with server key    │
│      │   6. Stream response back to app             │
│      │   7. Do NOT log conversation text            │
│      └──────────────────────────────────────────────┘
│                            │
│                            ▼
│                    ┌───────────────┐
│                    │ Anthropic API │
│                    │ (sonnet-4-6)  │
│                    └───────────────┘
```

### Components

**iOS app changes (~1 day of work)**

- `App/PaywallView.swift` — new view; presents Pro Hosted ($19.99/mo) + Pro BYOK toggle on a single screen
- `Engine/StoreKit.swift` — wraps StoreKit 2: `Product.products(for:)`, `purchase()`, `currentEntitlements`. No SDK — native APIs only
- `Engine/AnthropicClient.swift` — add hosted-mode branch: if `Store.hasActiveHostedSub`, POST to our server with receipt JWS instead of direct Anthropic
- `Settings/SettingsView.swift` — surface both Pro paths with explainer copy

**Server (Vercel function, ~1 day)**

- `api/messages.ts` — single endpoint, accepts `{persona, history, operatorTurn, receipt}`, returns Anthropic response
- `api/usage.ts` — read-only endpoint for the app to show "X / 200 games remaining" in Settings
- Receipt validation: Apple's documented JWS signature check (no external service needed)
- Per-user usage: Upstash Redis free tier (10K commands/day, plenty for v1.1 scale)
- Anthropic key: Vercel env var, never returned to client
- **No conversation text logged anywhere** — request body is forwarded, response is streamed back, nothing persists

**App Store Connect (~30 min)**

- Subscription Group: "Pro" — Apple terminology for related subs
- Subscription: "Pro Unlimited" — $19.99/mo, 1-month auto-renew
- Subscription Status URL (server-to-server notifications endpoint): `https://frameandfork.vercel.app/api/subscription-status`
- Localized subscription display name + description (Persuasion-Max voice)
- Family Sharing: **off** (avoids one $19.99 paying for 5 closers in a sales org)

## Spending caps & runaway protection

**Anthropic console:** set a $200/mo cap day-1. If 50 paid subs all play 200 games at $0.05 = $500 — but Marion's revenue at 50 subs × $17 net = $850, so $500 cost is still margin-positive. Cap at $200 lets the first ~80 power-users-worth of usage through.

**Vercel function:**
- Rate limit: 60 requests/min/receipt (5 games/min — fine for any real user, blocks any abuse)
- Hard daily cap per user: 50 games/day (avoids a single account burning the budget)

**Monitoring:**
- Vercel function logs go to a daily-summary Slack webhook (just `count` and `cost` aggregates, no content)
- Anthropic usage page checked weekly

## Risks

- **Receipt-validation edge cases**: refunded purchases, family-sharing edge cases, sandbox vs production receipts. StoreKit 2's JWS approach handles most; document the rest as known issues
- **Server outage = app outage** (for Pro Hosted users). Mitigation: app falls back to BYOK input prompt if hosted endpoint 5xx's for >30s
- **Anthropic outage** = same fallback behavior. Both surfaces share the same "Pro tier momentarily unavailable, try BYOK" UX
- **App Review on v1.1**: privacy posture change is the big one. Lead reviewer notes with the transparent explanation above; if rejected, the Resolution Center reply already has the pattern

## Out of scope for v1.1

- Web checkout for Pro Hosted (Apple-only purchase is sufficient at MVP scale)
- Team / multi-seat subscriptions (manual Stripe handles 1–5 teams; defer the StoreKit team flow to v1.2+)
- Refund handling beyond Apple's automatic flow
- Localization of the Paywall (English only)
