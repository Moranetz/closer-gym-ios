Frequently asked

What does Free tier include?

Everything that ships offline. Daily Drill, the full puzzle library (20 positions, growing), Lessons (the Atlas technique browser), Watch (master games), Profile (your rating and streak). No API key needed. Nothing is sent to any server.

What does Pro tier include?

The bot ladder: 15 adversarial buyer personas, ELO 1200 to 2400. Free-text live sparring. Live LLM detector for technique tagging. End-of-game scoring against the curriculum's Stage-4 rubric. Pro requires you to supply your own Anthropic API key in Settings. Cost is roughly $0.50 per game on your key.

Why do I need to provide my own API key?

v0.1 ships as bring-your-own-key. A hosted Pro tier (where you pay through the App Store or Stripe and we handle the API costs) arrives with v0.2. The current architecture has no server side, which is also why your data is fully private.

How do I add my Anthropic API key?

Open the Profile tab, tap the gear icon, tap Pro tier, paste your sk-ant-... key. It is stored in the iOS Keychain (not in UserDefaults, not in any logs). You can get a key from console.anthropic.com.

How does the puzzle ELO work?

Glicko-2, the same rating system chess.com uses for puzzles. Your puzzle rating starts at 1200. Each puzzle has a difficulty rating (1300 to 2200). When you solve correctly your rating moves toward the puzzle's difficulty; when you miss it moves away. Daily Drill streaks accumulate when you solve the day's puzzle correctly.

The buyer line on the puzzle does not feel realistic.

The buyer lines are presupposition-loaded and source from real operating contexts (CFO board narratives, procurement guidelines, founder burn rates). The candidate moves are intentionally written in chess-notation style (compressed tactical descriptions) rather than dialogue, because authored dialogue introduces "this was written by a language model" tells. Real-conversation texture lives in the linked Read Full Transcript sheets, which are sourced from published Voss, Klaff, Cardone, Tracy, and Belfort material.

What are the transcript "paraphrased reconstruction" warnings?

Most transcripts are verbatim quotation from the speaker's own published material. One (Belfort's Aerotyne cold call) is reconstructed from his Straight Line teaching plus the 2013 film script, because the original 1990s call recordings are not publicly available. Cards flagged "paraphrased" carry an in-app disclosure.

How do I reset my progress?

Settings → Clear all data. Deletes your puzzle solves, ratings, streaks, and Pro tier API key from the device. There is no cloud backup because nothing was ever uploaded.

The Daily Drill is the same puzzle as yesterday.

It should not be. The daily puzzle is selected deterministically by hashing the current date. If you see the same puzzle two days running, please file an issue with the date and the puzzle ID.

I found a bug.

Open an issue at Moranetz/closer-gym-ios with a description and a screenshot if you can. Include your iOS version and device model. Pull requests welcome.

Can I run the web version instead?

Yes. Source is at Moranetz/closer-gym. Self-host or run locally via npm run dev. Free tier works identically; Pro tier requires the same Anthropic API key.
