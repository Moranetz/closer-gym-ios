Frame & Fork is a sales-training app — "chess.com for closers." It trains the read-the-buyer
skill through chess-style puzzles, annotated master games, live sparring conversations, and
free-text role-play against AI buyers.

NO ACCOUNT OR LOGIN IS REQUIRED. NO API KEY IS REQUIRED TO PLAY THE APP.

WHAT YOU CAN TEST WITH NO KEY (nearly the entire app, fully offline):
  • Play tab — SPARRING: full multi-turn sales conversations against authored AI buyer
    personas (pick your line each turn, get graded, earn a rating). Works with no key,
    no network, no setup — tap Play → "Design partner at a Series A startup" → Spar.
  • Puzzles tab — 127 multiple-choice "best move" sales puzzles across 9 themes, with a
    graded reveal, a daily drill, and a review-your-misses queue.
  • Lessons tab — the 41-technique reference.
  • Watch tab (Master Games) — step through a real deal and guess the master's next move.
  • Profile — ratings, history, share card.

THE ONE OPTIONAL FEATURE THAT NEEDS A KEY — free-text live role-play:
Beyond the built-in sparring mode, the Play tab also offers FREE-TEXT games where an AI buyer improvises. Because the
app is a bring-your-own-key client (it does not resell AI access), it needs an Anthropic API key.

No demo key is provided: this feature is optional, is not part of the app's core offering, and
simply lets a user connect their own existing Anthropic account (like a Mastodon or RSS client
connecting to the user's own service). Every feature above it — sparring, all 127 puzzles,
lessons, master games, ratings — is fully reviewable with no key, no account, and no network.
If a key is ever entered: Play tab → any persona → "Start game" → type a few turns → "End"
produces a graded debrief saved under Profile → Game history.

PRIVACY: The app collects nothing on any server we control. Role-play text is sent directly
from the device to Anthropic using the entered key (disclosed in the privacy policy). The key
is stored only in the iOS Keychain.

ENCRYPTION: Standard HTTPS only; ITSAppUsesNonExemptEncryption = false (exempt).
